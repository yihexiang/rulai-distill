## G01 · 禮（纪纲）

- **术语**：禮
- **本书语境定义**：全书总纲第一词。「天子之職莫大於禮」——禮不是礼节虚文，而是「紀綱」，即支撑「天子統三公，三公率諸侯，諸侯制卿大夫，卿大夫治士庶人」这套上下相保秩序的总制度；其职能是「辨貴賤，序親疏，裁群物，制庶事」。礼坏则国坏：「先王之禮於斯盡矣」。
- **原文用法（支撑句）**：「臣聞天子之職莫大於禮，禮莫大於分，分莫大於名。何謂禮？紀綱是也；何謂分？君臣是也；何謂名？公、侯、卿、大夫是也。」「夫禮，辨貴賤，序親疏，裁群物，制庶事。」「貴以臨賤，賤以承貴……然後能上下相保而國家治安。故曰：天子之職莫大於禮也。」（均见第3段）
- **段号定位**：第3段（威烈王二十三年，卷首臣光曰，ck-0002）
- **古今差异注意**：今人说「禮」多指礼貌、礼仪、礼物；本书之禮是政治秩序本身（「禮之大體」即国本），且是君臣双向的身份准则——第122段貂勃「子為子之臣禮，吾為吾之王禮」。与「禮樂」连用时（第92段公子成「禮樂之所用也」）指华夏文明制度整体，非今之「音乐」。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：臣光曰直给。第144段魯仲連「棄禮義而上首功」是礼的反面判词；第85段齊王「飭君臣之義」是礼的诸侯级表述。血食一词出自礼/分论证链，见 G02 备注。

## G02 · 分（君臣）

- **术语**：分
- **本书语境定义**：「何謂分？君臣是也」——分是君臣上下之间的名分界限，是全书秩序的刚性判准：守分则上下相保，犯分则「天下共誅之」。其硬度到「當守節伏死」：纵有桀纣之暴，未受人归天命之前，臣子也只能守节伏死，不得擅行废立。
- **原文用法（支撑句）**：「何謂分？君臣是也」「非有桀、紂之暴，湯、武之仁，人歸之，天命之，君臣之分，當守節伏死而已矣」「誠以禮之大節不可亂也。故曰：禮莫大於分也。」「乃畏奸名犯分而天下共誅之也。」（均见第3段）
- **段号定位**：第3段（ck-0002）
- **古今差异注意**：现代「分」是份额、分开、分钟；本书之「分」= 名分/职分的法定边界，不可越一寸，且越界的后果不是丢脸而是「共诛」。另注意与现代「情分」无关。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：反面表述见第122段「君臣無異而上下無別」（谗田单者的罪状用语）、第85段「明父子之位」。**血食**（建议关键词，折入本条）：「以季札而君吳，則太伯血食矣」——血食=牲祭，书中是「社稷存续」的等价词；二子寧亡國而不為，是不肯以乱分换血食。现代「血食」指肉食/生食，语义完全不同。

## G03 · 名（爵位名号）

- **术语**：名
- **本书语境定义**：「何謂名？公、侯、卿、大夫是也」——名是爵位名号，是「分」的载体与对外宣告（「名以命之」）。全书逻辑链礼→分→名逐级收拢，因为「非名不著」：贵贱亲疏没有名就显不出来，故结论是「分莫大於名」。名的授予是君主专卖（「君之所司」）。
- **原文用法（支撑句）**：「何謂名？公、侯、卿、大夫是也」「非名不著……名以命之」「故曰：分莫大於名也。」（第3段）；「無其實，敢處其名乎？」（第76段，趙武靈王拒稱王）
- **段号定位**：第3段（ck-0002）；第76段（顯王四十六年，ck-0076）
- **古今差异注意**：现代「名」= 名字/名声，现代「名分」一词更近「名声、体面」——恰是本书要防的误读；本书之「名」是制度性爵位，「處其名」须有实（实力/功德）相副，赵武灵王「無其實，敢處其名乎」是标准态度。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：臣光曰以「正名」为细务而孔子先之，因「名不正則民無所措手足」。第113段蘇代「以名尊秦」是反向操弄名的案例；第74/76/79/113段稱王、貶號、稱帝诸事均属「名」的争夺。

## G04 · 器（法物）

- **术语**：器
- **本书语境定义**：「非器不形……器以別之」——器是名分的物质化（礼器、爵秩、车马服饰之等），把不可见的贵贱变成可见的差别。器与名同为「君之所司」，是君主专卖品，「不可以假人」。
- **原文用法（支撑句）**：「非名不著，非器不形。名以命之，器以別之，然後上下粲然有倫，此禮之大經也。」「惟器與名，不可以假人，君之所司也。」（第3段）；「居三代之傳器，器南，則兵至矣。」（第120段，東周武公）
- **段号定位**：第3段（ck-0002）；第120段（赧王三十四年，ck-0120）
- **古今差异注意**：现代「器」= 器具/器官/器重；本书之「器」特指体现等级的法物（重器、祭器、名器），私相授受即坏礼。第120段九鼎之「器」是天子共主地位的物证——楚欲圖周，「見祭器在焉故也」。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：**繁纓**（建议关键词，折入本条）：「昔仲叔於奚有功於衛，辭邑而請繁纓，孔子以為不如多與之邑……夫繁纓，小物也，而孔子惜之」——繁纓是诸侯车马之饰（非现代「繁密的缨络」），孔子所惜者是「不可以假人」的器。另见第117段樂毅「取寶物、祭器」、第138段觸龍「挾重器多也」、第85段「遷其重器」，皆此义。

## G05 · 名器

- **术语**：名器
- **本书语境定义**：名与器的合称，「禮之大經」的实操界面：名以命之、器以別之，二者既存则「上下粲然有倫」；「名器既亡，則禮安得獨在哉」；「名器既亂，則上下無以相有」。本书开篇大事件的定性即坏名器：天子「寵秩之，使列於諸侯」，是把名器送人。
- **原文用法（支撑句）**：「名以命之，器以別之，然後上下粲然有倫，此禮之大經也。名器既亡，則禮安得獨在哉？」「誠以名器既亂，則上下無以相有故也。」（第3段）
- **段号定位**：第3段（ck-0002）
- **古今差异注意**：现代汉语无「名器」常用义（偶见指名酒/著名器物）；本书是政治术语，指爵位名号＋礼器等差体系，是礼的可操作界面。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：与 G03（名）、G04（器）为母子条目；三重验证通过后宜合并为一卡三词。「政亡，則國家從之」（第3段）是名器失守的后果句。

## G06 · 綱紀

- **术语**：綱紀（纪纲）
- **本书语境定义**：「何謂禮？紀綱是也」——纲纪是礼的网状结构：纲举目张，即「天子統三公……卿大夫治士庶人」的统属关系。动词性用法「頓綱振紀」指整顿这套统纪。其崩解有可观测序列：「綱紀散壞，下陵上替，諸侯專征，大夫擅政」。
- **原文用法（支撑句）**：「何謂禮？紀綱是也」「豈非以禮為之綱紀哉」（第3段）；「幽、厲失德，周道日衰，綱紀散壞，下陵上替，諸侯專征，大夫擅政。禮之大體，什喪七八矣。」（第3段）；「其才足以頓綱振紀」（第77段，臣光曰论孟尝君养士）
- **段号定位**：第3段（ck-0002）；第77段（顯王四十七年，ck-0077）
- **古今差异注意**：现代「纲纪」多泛化指「纲常纪律」（且今多说「败坏纲纪」近一般纪律失范）；本书是具体的政治统系，且「散壞」四步（下陵上替→专征→擅政）是可作失败模式清单的诊断序列。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01；乱序诊断清单）
- **备注**：「禮之大體，什喪七八矣」是程度量化表述；周室残存的原因被归结为「尚能守其名分」（见 G07）。

## G07 · 名分

- **术语**：名分
- **本书语境定义**：名与分的合称，全书枢轴词。周室地不大於曹滕、民不众於邾莒而能「宗主天下」数百年，「徒以名分尚存故也」；名分是「畏」的对象——「畏奸名犯分而天下共誅之」。三晉受封则「區區之名分復不能守而並棄之。先王之禮於斯盡矣」。
- **原文用法（支撑句）**：「蓋以周之子孫尚能守其名分故也」「徒以名分尚存故也」「是區區之名分復不能守而並棄之也。先王之禮於斯盡矣。」（均见第3段）
- **段号定位**：第3段（ck-0002）
- **古今差异注意**：【重点】现代说「名分」近于「名声、体面、关系定位」；本书之「名分」是天下之公器的法定归属，犯分不是丢面子，是招致「天下共诛」的死罪。一软一硬，勿以今义轻之。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：名分的边界案例是**隧**（建议关键词，折入本条）：「昔晉文公有大功於王室，請隧於襄王，襄王不許，曰：『王章也。未有代德而有二王，亦叔父之所惡也。』」——隧=天子葬礼（与现代「隧道」义完全不同）；以大功之臣亦不得请，证名分不可交易。反向操作案例见 G14（三晉）。

## G08 · 天子

- **术语**：天子
- **本书语境定义**：名分秩序的顶点与授勋人：「天子之職莫大於禮」，权能是「統三公」与授予诸侯之位（「受天子之命而為諸侯，誰得而討之」）。本书对天子的批判点是授权失职——「天子既不能討，又寵秩之」。
- **原文用法（支撑句）**：「天子統三公，三公率諸侯，諸侯制卿大夫，卿大夫治士庶人。」「不請於天子而自立，則為悖逆之臣。天下苟有桓、文之君，必奉禮義而征之。」（第3段）；「名為天下共主……攻之者名為弒君。」（第120段）；「挾天子以令於天下，天下莫敢不聽。」（第83段，張儀语）；「秦無已而帝，則將行其天子之禮以號令於天下。」（第144段，魯仲連语）
- **段号定位**：第3段（ck-0002）；第83段（慎靚王五年，ck-0083）；第120段（赧王三十四年，ck-0120）；第144段（赧王五十七年，ck-0144）
- **古今差异注意**：现代「天子」≈皇帝别称或「天命之子」式俗语；本书中天子首先是礼的执行官与名器的出让人——威烈王二十三年的关键剧情正是天子把「諸侯」之名送给了三晉。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：**共主**（折入本条）是本书对天子实质的另称：第120段「名為天下共主」「誅殘天下之共主」——地少民寡而名分未亡。**帝**（折入本条）是比王更高一级的名号争夺：第113段秦稱西帝、立齊為東帝，蘇代勸「釋帝以收天下之望」；第144段魏趙谋「尊秦為帝」。第116段齊湣王「欲并二周，為天子」是僭越标本。

## G09 · 諸侯

- **术语**：諸侯
- **本书语境定义**：五等爵中的列国之君，「分」的中段：上受天子之命、下制卿大夫。本书强调其位置是授职产品而非实力产品——「今請於天子而天子許之，是受天子之命而為諸侯也」。
- **原文用法（支撑句）**：「初命晉大夫魏斯、趙籍、韓虔為諸侯。」（第3段）；「齊田和會魏文侯、楚人、衛人于濁澤，求為諸侯。魏文侯為之請於王及諸侯，王許之。」（第16段）；「初命齊大夫田和為諸侯。」（第18段）；「是時周室微弱，諸侯莫朝，而齊獨朝之」（第55段）
- **段号定位**：第3段（ck-0002）；第16段（安王十三年，ck-0016）；第18段（ck-0018）；第55段（顯王二十一年，ck-0055）
- **古今差异注意**：现代「诸侯」常用于比喻割据势力/各方大佬（游戏、职场语）；本书是法理爵位，且全书反复演示授予程序的严肃性（三晉、田和皆須「請於天子而天子許之」）。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：削爵的对应词是**家人**（折入本条）：「魏、韓、趙共廢晉靖公為家人而分其地」（第27段）、「遷魯頃公於莒，為家人，絕祀」（第146段）——家人=削去爵位的平民（非现代「家庭成员」），与血食断绝互为表里。另第59段「王致伯於秦，諸侯皆賀秦」是名分交易彻底市场化后的场景。

## G10 · 卿大夫

- **术语**：卿大夫
- **本书语境定义**：诸侯之下的执政层，「名」的第三等（「何謂名？公、侯、卿、大夫是也」），职能「卿大夫治士庶人」。本书开篇事件的主角（晉大夫魏斯等）即此层；其越级（「大夫擅政」）是纲纪散坏的前兆与尺度。
- **原文用法（支撑句）**：「何謂名？公、侯、卿、大夫是也」「諸侯制卿大夫，卿大夫治士庶人」「諸侯專征，大夫擅政」（第3段）；「君出言自以為是，而卿大夫莫敢矯其非；卿大夫出言亦自以為是，而士庶人莫敢矯其非。」（第26段，子思）；「晉用六卿而國分」（第78段，繆留）
- **段号定位**：第3段（ck-0002）；第26段（安王二十五年，ck-0026）；第78段（顯王四十八年，ck-0078）
- **古今差异注意**：现代「卿大夫」生僻，易与「宰相/大臣」混同；本书中它是爵级名分的一环——问题不在官大官小，而在是否「矯其非」、是否「擅政」，即是否越过自己的分。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：第26段子思「君不君，臣不臣」是名分失序的概括判词；「六卿」是卿大夫层尾大不掉的极端形态（晉）。第3段李克「卑不謀尊，疏不謀戚」是同层的自我戒惧。

## G11 · 智伯

- **术语**：智伯（智襄子瑤）
- **本书语境定义**：本书第一位「才勝德」标本，五贤一不仁，「以其五賢陵人，而以不仁行之」。在名分秩序里他是「奸名犯分」的活例：势力足以逐君自为而不敢为，畏的是「天下共誅」；其亡又被归结为才德问题（「智伯之亡也，才勝德也」）。
- **原文用法（支撑句）**：「智伯之於晉，其勢皆足以逐君而自為，然而卒不敢者，豈其力不足而心不忍哉？乃畏奸名犯分而天下共誅之也。」（第3段）；「臣光曰：智伯之亡也，才勝德也……才者，德之資也；德者，才之帥也。」「德勝才謂之君子，才勝德謂之小人。」（第3段）；「智氏之信韓、魏也，從而伐趙，攻晉陽城，勝有日矣，韓、魏叛之，殺智伯瑤於鑿台之下。」（第128段，黃歇引古）
- **段号定位**：第3段（ck-0002/ck-0003）；第128段（赧王四十二年，ck-0128）
- **古今差异注意**：现代「智伯」仅存为历史名词；本书赋予其双重框架义——既是名分秩序的「畏」例，又是才德之辨的「小人」例。两个框架叠加才是本书的智伯，拆卡时勿只取其一。
- **被哪些能力使用**：待 Phase 3 回填（预计：才德两栏打分 F02；名分三层扫描 F01）
- **备注**：同场人物**韓康子**（建议关键词，折入本条）：「智伯請地於韓康子」（第3段），「韓康子驂乘」；魏桓子见 G13。才德四分法（聖人/愚人/君子/小人）见第3段臣光曰，是独立框架 F02 的直给来源。同段叙事另见智果諫立嗣「智宗必滅」——家族版同款预判。

## G12 · 趙襄子

- **术语**：趙襄子（無恤）
- **本书语境定义**：趙氏少主，名分秩序中的「守分者」镜像：不取長子（民罷力以完之，又斃死以守之，其誰與我）、不取邯鄲（浚民之膏澤以實之，又因而殺之，其誰與我），而走晉陽——因为「先主之所屬，尹鐸之所寬，民必和矣」。
- **原文用法（支撑句）**：「襄子曰：『……其晉陽乎，先主之所屬也，尹鐸之所寬也，民必和矣。』乃走晉陽。」「襄子夜使人殺守堤之吏，而決水灌智伯軍。」「趙襄子漆智伯之頭，以為飲器。」（均见第3段）
- **段号定位**：第3段（ck-0002/ck-0003）
- **古今差异注意**：人名无显著古今歧义；但「襄子」在书中至少指三人——趙襄子無恤、智襄子瑤（第3段「智襄子為政」）、田襄子盤（第14段）——引用必须带国氏/氏称。
- **被哪些能力使用**：待 Phase 3 回填（预计：保障型经营 F 类；晋阳之守案例）
- **备注**：豫讓事提供两个制度词：**委質為臣**=臣服的定名仪式（「既已委質為臣，而又求殺之，是二心也」）；**飲器**=溺器（非现代「飲酒之器」，「漆智伯之頭以為飲器」是极致之辱）。襄子卒后「弟桓子嘉逐浣而自立」（第3段）——此桓子是趙桓子，勿与魏桓子混（见 G13）。

## G13 · 魏桓子

- **术语**：魏桓子（虎）
- **本书语境定义**：魏氏家主，三家分晉的参与者。书中以两个身体语言定其立场：藍台宴在座被智伯一方戲侮（「智伯戲康子而侮段規」），灌晉陽时「魏桓子御，韓康子驂乘」，闻智伯自曝「水可以亡人國」而「肘康子，康子履桓子之跗」——预见汾水可灌安邑、絳水可灌平阳，故暗通赵氏。
- **原文用法（支撑句）**：「及智宣子卒，智襄子為政，與韓康子、魏桓子宴於藍台。」「智伯行水，魏桓子御，韓康子驂乘。智伯曰：『吾乃今知水可以亡人國也。』桓子肘康子，康子履桓子之跗，以汾水可以灌安邑，絳水可以灌平陽也。」（均见第3段）
- **段号定位**：第3段（ck-0002）
- **古今差异注意**：「桓子」在本书至少指两人：魏桓子（虎，三家分晉之魏）与趙桓子（襄子之弟嘉，第3段「襄子卒，弟桓子嘉逐浣而自立」）。今人读史常混，须以国氏区分。
- **被哪些能力使用**：待 Phase 3 回填（预计：唇齿结构 F05；三家分晉案例）
- **备注**：任章諫桓子與地（「無故索地，諸大夫必懼；吾與之地，智伯必驕」）是驕敵之術的早期用例；絺疵察韓魏必反（第3段）补足情报侧。智國諫智伯（「主不備，難必至矣」）则是同宴的反面声音。

## G14 · 三晉

- **术语**：三晉
- **本书语境定义**：韓、趙、魏三家的合称，本书首年大事件的当事方。在名分框架里三晉是试纸：不請而自立=悖逆之臣；請而天子許=反得免討——「故三晉之列於諸侯，非三晉之壞禮，乃天子自壞之也」。
- **原文用法（支撑句）**：「初命晉大夫魏斯、趙籍、韓虔為諸侯。」「夫三晉雖強，苟不顧天下之誅而犯義侵禮，則不請於天子而自立矣。不請於天子而自立，則為悖逆之臣。」「今請於天子而天子許之，是受天子之命而為諸侯也，誰得而討之！故三晉之列於諸侯，非三晉之壞禮，乃天子自壞之也。」（均见第3段）；「魏、韓、趙共廢晉靖公為家人而分其地。」（第27段）
- **段号定位**：第3段（ck-0002）；第27段（安王二十六年，ck-0027）；另见第17段（吳起「北卻三晉」）、第57段（「衞更貶號曰侯，服屬三晉」）、第143段（「三晉割地以求安」）
- **古今差异注意**：现代「三晉」基本仅指山西地域代称；本书是政治实体（三家）＋法理过程（从晉大夫到諸侯的授职），且承担全书开篇的因果论功能——「天子自壞」的归责结构。
- **被哪些能力使用**：待 Phase 3 回填（预计：名分三层扫描 F01）
- **备注**：三晉之强是「力」，周室之存是「名」——本书开篇即判定：力可夺国，名可召诛。第143段子順「三晉割地以求安」是三十余年后名分秩序彻底市场化的收尾状。

## G15 · 晉陽

- **术语**：晉陽
- **本书语境定义**：趙氏封邑，本书「保障」型经营的范例：尹鐸「損其戶數」以宽民，故襄子危难时「民必和矣」，被围灌水「民無叛意」。与「繭絲」型（榨取式）经营对举——「以為繭絲乎？抑為保障乎？」
- **原文用法（支撑句）**：「簡子使尹鐸為晉陽。請曰：『以為繭絲乎？抑為保障乎？』簡子曰：『保障哉！』尹鐸損其戶數。」「襄子曰：『……其晉陽乎，先主之所屬也，尹鐸之所寬也，民必和矣。』乃走晉陽。」「三家以國人圍而灌之，城不浸者三版。沈竈產鼃，民無叛意。」（均见第3段）
- **段号定位**：第3段（ck-0002）；另见第128段（黃歇「攻晉陽城」，ck-0128）
- **古今差异注意**：今「晉陽」多指太原晉陽古城/晉陽湖一类地理名；本书之晉陽（今太原西南）语义负载是「保障」与「民和」，不是地理词——它回答的是「把城建给谁防谁」的路线问题。
- **被哪些能力使用**：待 Phase 3 回填（预计：保障型经营 F 类；三家分晉案例）
- **备注**：「繭絲乎？抑為保障乎？」是本书第一组治民路线选择题；简子「無以尹鐸為少，無以晉陽為遠，必以為歸」是后备基地配置原则。
