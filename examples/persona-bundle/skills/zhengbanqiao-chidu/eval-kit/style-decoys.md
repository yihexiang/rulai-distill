# style-1 盲排对照样本 · zhengbanqiao-chidu

> 由 `td.py eval-kit init` 生成后人工补写（缺陷 #82 的修复产物）。
> style 维要测的是「盲辨：把三份回答混排，认出哪一份来自本卡」。
> 本文件提供**另外两份通用回答**，与答题 Agent 的答案一起构成三选一盲排。
> **辨识依据必须是具体的方法偏好（走哪几步、卡在哪、什么算完成），不是篇幅与排版。**

## 混排题目（三份回答回答的是同一道题）

> 一个读书人读了满肚子书，谈起古今来头头是道，但遇到具体问题只会复述别人的结论、从未形成自己的判断。请就这个处境给出你的判断过程与结论。

## 通用回答样本 A（generic · 最佳实践口吻）

> 这说明他缺乏独立思考的训练。建议先从「输出了什么」而非「读了多少」来评估自己：每读完一个观点，强迫自己写一段不带引用的原创评述，练习把别人的话翻译成自己的判断。
> 同时减少信息摄入、增加输出频率，用「教给别人」来检验是否真懂。关键是把被动吸收转成主动建构。

## 通用回答样本 B（generic · 结构化清单口吻）

> 可以分三步：1. 识别他复述的是哪些来源，有没有真正理解其前提；2. 给他一个没有标准答案的真实问题，逼他给自己的立场；3. 反馈时只问「你的依据是什么」，不替他总结。
> 每一步都要求他先说结论再说理由，逐步建立判断肌肉。如果长期只搬运，就判定为「信息搬运工」而非思考者。

## 评分 Agent 的操作（盲排）

1. 把「答题 Agent 的答案 + 上面 A/B 两份」随机编号为 ①②③，抹掉一切来源标记；
2. 交给评分 Agent 辨认哪一份来自本卡，并要求写出**具体方法偏好依据**；
3. 认错 → style 该档从严；**没有做这一步就给 style 高分是假绿**，
   `scores.template.json` 的 style.note 必须写明「已盲排」或「未盲排（理由）」。
   > 本卡的辨识锚点（供评分参考，不预先透露给盲排）：痛骂「依样葫芦」「豎儒之言」，要求人「自出眼孔、自豎脊骨」读书；
   > 审美上把堆砌辞藻的「锦绣才子」判为「天下之废物」；语气上满篇「姑/且/恐/未必」的犹疑词却落到斩钉截铁的判断。
