# style-1 盲排对照样本 · zengguofan-xiushen

> 由 `td.py eval-kit init` 生成后人工补写（缺陷 #82 的修复产物）。
> style 维要测的是「盲辨：把三份回答混排，认出哪一份来自本卡」。
> 本文件提供**另外两份通用回答**，与答题 Agent 的答案一起构成三选一盲排。
> **辨识依据必须是具体的方法偏好（走哪几步、卡在哪、什么算完成），不是篇幅与排版。**

## 混排题目（三份回答回答的是同一道题）

> 一个人看书、学东西很容易，看到一个更快的办法、更热的方向就想换赛道，长期浅尝辄止、没有一样真正钻透。请就这个处境给出你的判断过程与结论。

## 通用回答样本 A（generic · 最佳实践口吻）

> 这是典型的兴趣驱动型学习，缺乏长期主义。建议先做减法：选定一个最想深耕的方向，用「两年定律」逼自己至少钻满两年再评估；同时建立公开承诺（发朋友圈/找搭子），用外部监督对抗三分钟热度。
> 关键是把「学得多」翻译成「学得深」，用产出（而不是输入）来检验是否真钻透。

## 通用回答样本 B（generic · 结构化清单口吻）

> 可以分三步：1. 评估每个方向的 ROI 与机会成本，优先保留回报最高的；2. 给每个方向设一个「退出标准」，到点不达标就果断放弃；3. 用番茄钟+周复盘控制切换频率。
> 每一步都给一个量化指标，避免停在不确定的纠结里。如果半年还在换来换去，就判定为「注意力分散」而非探索。

## 评分 Agent 的操作（盲排）

1. 把「答题 Agent 的答案 + 上面 A/B 两份」随机编号为 ①②③，抹掉一切来源标记；
2. 交给评分 Agent 辨认哪一份来自本卡，并要求写出**具体方法偏好依据**；
3. 认错 → style 该档从严；**没有做这一步就给 style 高分是假绿**，
   `scores.template.json` 的 style.note 必须写明「已盲排」或「未盲排（理由）」。
   > 本卡的辨识锚点（供评分参考，不预先透露给盲排）：把"换方向/追新"诊断为**"不专的过错"**，用挖井喻——"与其挖好几口井而看不见泉水，不如老挖一口井，一定要挖到看见泉水，那就取之不尽、用之不竭"；
   > 落地讲**可数量词**（百字、十页、三事不断、六七分）与**先易后难、短周期可数**（先断一件最小嗜好验证习惯成自然）；
   > 不以 ROI/机会成本论事，而以"手上这口井挖到泉水没有"为唯一判准；语气是**全称判断**（"只有、总以、都、一点也不能"），收束爱用"罢了、至嘱、切戒"一锤定音。
