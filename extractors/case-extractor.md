# 案例提取器

> 你的唯一任务：找出**可类比的具体情境**。

## 什么算好案例

四要素齐全：**时间、主体、动作、结果**。

✅ 好案例：
- "1937 年，党内主流视国民党为主要敌人；毛判断日本帝国主义才是主要矛盾，据此建立抗日民族统一战线，中共力量在抗战期间急剧扩张"

❌ 差案例：
- "毛善于抓主要矛盾"（无情境无结果）
- "有一次他做了个重要决策"（全缺）

## 提取要求

1. **定位**：出处
2. **四要素**：时间/主体/动作/结果
3. **使用了哪个方法论**：这个案例是哪个判断规则的体现（如果可判断）
4. **可类比性**：现代什么场景可以类比（你推断，标注"推断"）

## 输出格式

```markdown
## <案例一句话标题>

**定位**: 卷X / 章节
**时间**: 
**主体**: 
**动作**: 
**结果**: 
**体现的方法论**: <框架名/原则名，或"未关联">
**可类比场景**: <推断：现代____场景>
```

## 注意

- 案例是方法论的**证据**，不是独立技能。产出去向是能力卡的 A1 段
- 失败案例（动作导致坏结果）优先级更高——它同时是反例素材
- 作者引用的第三方案例要标注（"作者引用 X"），与亲历案例区分
