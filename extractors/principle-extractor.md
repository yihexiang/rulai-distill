# 原则提取器

> 你的唯一任务：找出**带条件的判断规则**。

## 什么算原则

**"当…时，应该…"结构**，能在具体情境下指导决策的：

✅ 是原则：
- "当增长快于现金流时，优先解决账期问题"
- "删过头时，把删掉的加回 10%"（有条件：删过头）

❌ 不是原则：
- "要重视现金流"（无条件无动作）
- "简化很重要"（不可操作）

**判据：能写成一行 if-then 吗？** 能 → 原则；写不出条件 → 可能是废话，标记"疑似废话"交给验证阶段处理。

## 提取要求

1. **定位**：精确出处
2. **原文摘录**：≤50 字
3. **触发条件**：什么情况下适用（作者说的 + 你推断的，分开标注）
4. **判断动作**：应该做什么
5. **反例**：什么情况下这个判断会错（作者警告的 + 你推断的）
6. **强度**：strong / single

## 输出格式

```markdown
## <原则一句话概括>

**定位**: 卷X / 章节 / 段落
**原文摘录**: "> ……"
**触发条件**: 当____时（作者明确说的）
**判断动作**: 应该____
**已知反例**: ____时失效（作者警告的）
**推断反例**: ____（我的推断，需验证）
**强度**: strong
```

## 注意

- 原则经常以否定形式出现："绝不在____时____"——同样有效，触发条件就是被否定的那个情境
- 作者引用别人的原则要标注来源（"作者引用 X 的观点"），和作者自创的分开
- **"推断反例"必填**——这是阶段 1.5 关卡 3（任务效用）的核心素材。想不出反例的原则大概率是废话。
