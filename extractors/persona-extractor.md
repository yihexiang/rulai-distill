# 人物提取器（认知植入专用）

> 你的唯一任务：为一个**人**收集认知植入所需的素材。
> 注意：你不是在提取"他说了什么"，而是在挖"他**为什么**这样想"。

## 与内容蒸馏的根本区别

| | 内容蒸馏 | 人物蒸馏 |
|---|---|---|
| 提取对象 | 方法论（可独立成立） | 认知结构（依附于人的经历） |
| 核心问题 | 这个方法怎么用 | 他为什么形成这个判断 |
| 关键素材 | 步骤、条件、完成标准 | 信念来源、失败、矛盾 |
| 禁忌 | 硬把观点做成技能 | 提取成"语气模仿" |

## 六类素材（按优先级）

### 1. 信念及其来源（最重要）

**格式**：信念 + 因为什么经历形成。

❌ "他重视第一性原理"（无来源）
✅ "他习惯拆到物理极限，因为早期造火箭时被供应商报价震惊，发现原材料成本只占成品的 2%"

**判据**：每条信念必须能回答"他为什么信这个？"。答不出来的信念标记`来源缺失`，后续要么补调研，要么标注为推测。

### 2. 关键决策与事后反思

- 具体决策：什么时间、什么选项之间、选了什么
- **为什么这么选**（当时的判断依据）
- **事后怎么看**（后悔/坚持/修正）

无反思的决策记录价值减半——它只是经历，不是认知。

### 3. 真实失败

- 他自己承认的失败（公开场合说的，不是传记作者的推断）
- 失败教会了他什么

### 4. 内在矛盾

真实的人有矛盾，这才是辨识度来源：

> 示例：马斯克一边说"第一性原理，不类比"，一边大量使用物理学类比来解释问题。

矛盾不是缺陷，是**认知指纹**。只提取一致信念的人物技能会退化成平面化标签集合。

### 5. 认知边界

- 他明确说过不懂的领域
- 从未公开讨论过的话题（这部分要在技能里标注"未知，非推测"）

### 6. 表达 DNA（六维结构化，对齐 `td.py research` 的 03-expression-dna 车道）

> 写不出辨识度的表达 DNA，人物技能会退化成通用 AI 腔。六个维度分别取样，**拒绝凭印象概括**。

| 维度 | 提取什么 | 取样指引 |
|---|---|---|
| 句式偏好 | 长句/短句、疑问/陈述、类比密度、先结论还是先铺垫 | 从访谈转录里数：平均每句字数、反问占比、类比频次 |
| 词汇特征 | 高频词、专属术语、禁忌词、口头禅 | 列 Top-10 高频实词；标注自造词 |
| 节奏感 | 转折方式、论证密度、是否爱用清单/并列 | 看他怎么组织一个长论证（层层递进 vs 并列铺陈） |
| 幽默方式 | 讽刺 / 自嘲 / 荒诞 / 冷幽默 / 不幽默 | 找 2-3 处真实幽默样本，判类型 |
| 确定性表达 | 「我不确定」型 还是 「很明显」型 | 面对不确定问题时，他的默认措辞 |
| 引用习惯 | 爱引谁、引什么类型（数据/名人/自身经历） | 区分「引数据」「引权威」「引自己经历」 |

**输出要求**：每个维度给 1-2 个**真实样本句**（带出处），禁止只写「他说话很直接」这类无样本结论。这条维度最终落进认知植入卡的「我说话的方式」一节（见 `templates/PERSONA.md.template`）。

## 心智模型三重验证（原料 → 模型，人物蒸馏的核心工序）

六类素材是**原料**；心智模型是**成品**。从素材池到认知植入卡的「我看问题的方式」之间，
必须过三重验证（移植自 nuwa）。

> **先分清两条「三重验证」**（名字像、对象不同，混用会漏检）：
> - **cangjie 的候选单元三重验证**（阶段 1.5）：验「这条**方法论**能不能独立成立」——来源充分性 / 可执行性 / 任务效用；
> - **本节的nuwa 心智模型三重验证**：验「这个**模型**是不是这个人特有的」——跨域复现 / 生成力 / 排他性。
>   人物蒸馏走完第一条后，**还必须过本条**，否则产出的是"把他的书摘写成他的思维"。

| 重 | 验什么 | 通过标准 | 机械判据（尽量） |
|---|---|---|---|
| ① 跨域复现 | 这个模型是否在 **≥2 个不同领域/话题**里都出现 | 同一判断模式在著作(01) / 对话(02) / 决策(05) 等**≥2 个车道**各有实例 | 车道命中数 ≥2（`td.py research merge` 的车道覆盖表可数） |
| ② 生成力 | 能否据此推断他对一个**新问题**的立场 | 用一个素材没讲过的问题试推，推断不与他已知立场矛盾 | 留出题：`eval-kit` 人物预设的「超范围推断题」做一致性测试 |
| ③ 排他性 | 是不是「所有聪明人都会这样想」 | 换成一个 generic 聪明人，会给出**不同**判断 | 对照 no-skill 基线答案：基线也这么说 → 排他性存疑（模型自身功劳不算人物功劳） |

**降级规则**（nuwa 原规，本包沿用）：

- 三重全过 → **心智模型**（进「我看问题的方式」，取 3-7 个，宁少勿多）；
- 只过 1-2 重 → 降级为**决策启发式**（「如果 X 则 Y」式快速规则，挂在该模型相关段落，不单列）；
- 0 重 → **不纳入**（那是通用道理，不是这个人的认知指纹；写进去就是把人神化）。

**为什么排他性不可省**：缺了它，人物技能会退化成通用鸡汤合集——而这正是 FIDELITY
「反自评」与 utility「no-skill 对照」在同一条纪律上的延伸：**基座模型本身会的不算这个人的**。

## 输出格式

```markdown
## <人物名> · 素材池

### 心智模型（3-7 个，须过三重验证）
1. **<模型名>** — <一句话：他用什么镜片看世界>
   - 三重验证：跨域<车道实例≥2>｜生成力<留出题结论>｜排他性<与 no-skill 基线的差异点>
   - 局限：<失效条件>
2. ...
（未过三重验证的候选：降级为决策启发式或丢弃，在此列明"降级 N 条 / 丢弃 N 条"及原因）

### 信念（5-7 条）
1. **<信念一句话>**
   - 来源：<具体经历>
   - 强度：strong（多次公开提及）/ single（一次但详细）

### 关键决策（3-5 个）
### 失败（2-3 个）
### 矛盾（≥2 对）
### 认知边界（≥3 条）
### 表达方式
```

## 门槛判断

**不是所有人都适合蒸馏。** 判断素材充足度：

| 信号 | 判定 |
|---|---|
| 信念 + 来源 ≥5 条，决策有反思，失败真实 | ✅ 可蒸馏 |
| **心智模型过三重验证 ≥3 个** | ✅ 进「我看问题的方式」；**<3 个 → 在认知边界显式标注「模型层证据不足，以下思维习惯为低置信推断」** |
| 信念有但来源模糊，决策无反思 | ⚠️ 降级：标注"素材不足，以下维度为推测" |
| 只有观点没有经历 | ❌ 不适合：改用内容蒸馏（提取他的方法论而非他这个人） |

素材不足时**不要硬造**。产出物里推测部分必须在"认知边界"里显式标注。
