# 术语提取器

> 你的唯一任务：找出**专有名词与语境特定义**。
> 定义一律取"在这本书里指什么"，不是词典义。

## 什么算需要提取的术语

**在该内容语境中有特定含义**，离开语境会被误解的：

✅ 要提取：
- "主要矛盾"——特指"起领导决定作用的那个矛盾"，不是"最重要的矛盾"
- "白痴指数"——特指"成品价/原材料成本比"，不是字面的骂人话

❌ 不提取：
- 通用词（"增长""用户"）
- 行业通用术语（除非作者给了自定义）

## 输出格式

```markdown
## <术语>

**定位**: 首次出现处
**本书定义**: <作者的原义，可引原文>
**与通用理解的差异**: <如果字面意思会误导，写清差在哪>
**被哪些能力使用**: <框架名/原则名列表>
```

## 为什么重要

术语表（GLOSSARY）是跨技能沟通的公共底座。同一本书拆出的 10+ 技能，对"主要矛盾"的理解必须一致，否则路由到不同技能后给出的判断会互相矛盾。

**每个术语必须标注"被哪些能力使用"**——这是阶段 3 建依赖图的素材。
