# 阶段 0 · 整内容理解（Adler 分析）

> 目标：在提取任何单元之前，先建立全局认知图。
> 跳过这一步，产出的就是"看起来像方法论的书摘"。

## 为什么必须先做

蒸馏失败最常见的原因不是提取能力不足，而是**没区分"方法论"和"临时表述"**：

| 内容类型 | 是否可蒸馏 | 特征 |
|---|---|---|
| 方法论 | ✅ 可 | 跨情境稳定、可操作、有完成标准 |
| 观点 | ⚠️ 需转化 | 有倾向但无操作路径 |
| 背景叙述 | ❌ 不可 | 只在原语境成立，抽出即失真 |
| 案例 | ⚠️ 需标注 | 本身不可执行，但可作为方法论的证据 |
| 作者自述的临时判断 | ❌ 不可 | 只在特定时间点成立 |

一份 190 万字的《毛选》里，能直接蒸馏成独立技能的可能只有 18 个（18/190万 ≈ 万分之一）。**阶段 0 的任务就是提前形成这个判断力**，否则会在阶段 1 产出上百个待验证候选，白白消耗预算。

## 产出物：BOOK_OVERVIEW.md

模板见 `templates/BOOK_OVERVIEW.md.template`，必填五项：

### 1. 作者/讲述者立场

不是简介，是**立场地图**：
- 核心主张是什么（用一句话说清）
- 他反对什么（往往比主张更能界定边界）
- 他假设了什么前提（这些前提不成立时，方法论就失效）

### 2. 结构骨架

- 内容的组织方式（按时间？按主题？按问题？）
- 各部分的功能（铺垫 / 论点 / 证据 / 应用）
- **哪些部分是核心，��些是外围**（决定后续提取的优先级）

### 3. 核心论点清单

先列 5-10 条，不做提取。目的是建立"全局地图"，避免提取阶段各说各话。

### 4. 隐含假设

**这一项最容易被跳过，也最重要**。任何方法论都依赖前提：

> 示例：矛盾分析法隐含假设"矛盾是可识别的"和"主要矛盾在一定时期内稳定"。在快速变化的市场里，第二个假设经常不成立。

把假设显式写出来，后面 B 段的"不适用情况"才有依据。

### 5. 适用边界

- 这套方法论针对什么规模/阶段的问题
- 明确不处理什么
- 什么信号出现时，说明已经超出它的适用范围

## 长内容预处理（>5 万字必做）

```
td.py chunk  <source.md> --max-chars 4000     # 结构感知分块 + 索引 + 确定性缓存
td.py index  <source.md>.td --grep <关键词>    # 按标题路径检索相关块，避免全量读入
td.py preview <source.md>.td                  # 人工确认切分是否合理
```

分块规则（内置，已被回归测试覆盖）：

1. **尊重标题层级边界**——不跨章节拼块
2. 单块 ≤ `--max-chars`（默认 4000 字符）
3. 单个元素超长时，按**句边界**二次切分，不硬切丢内容
4. 每块保留 `heading_path` 与 `element_ids`，可回溯原文
5. **确定性缓存**：源文件 sha256 未变则跳过重算，重复运行不重复烧 token

**不要做的事**：直接分块后并行提取再拼接结果。分块会切断论证链条，
提取出的单元无法判断"是否被后文推翻"。正确做法是**先用 index 检索定位相关块**，
再把相关块的原文喂给提取 Agent。
