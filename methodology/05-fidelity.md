# FIDELITY 出厂质检细则

> **本技能的核心差异点。** 其他蒸馏流程解决"生成"，本文件解决"证明生成的东西真的对"。

## 为什么要独立评分 Agent

依据：SkillLens 论文（arXiv 2605.23899）实证 **LLM 自评 skill 质量准确率仅 46.4%**——接近随机猜测。

这个数字的含义是：**让写 skill 的 Agent 自己判断 skill 好不好，结果约等于抛硬币。** 因此评分必须由独立 Agent 完成，且该 Agent 不知道评分维度。

## 铁律

1. **答题 Agent 与评分 Agent 必须是两个独立 Agent。** 绝不合并成一个会话。
2. 答题 Agent 禁止联网（只读技能目录内文件），防止现场发挥。
3. 评分 Agent 不参与答题，只对照原始内容判定。
4. 出题避开技能内已有示例对话，防止背答案。
5. 重要结论建议 2 个评分 Agent 独立跑，**分差 >10 分人工复核**。

## 五个维度（总分 100）

### 1. 立场/结论一致性（30 分）

**测什么**：对内容明确表达过的判断，技能的回答方向是否一致。

**怎么测**：出 3 道"内容中明确讲过"的问题，每题 10 分。
- 方向和细节都对 = 10
- 方向对细节偏 = 6
- 立场偏离 = 0

**出题要求**：必须是内容反复论述过的判断，不能是边缘案例。

### 2. 风格辨识度（20 分）

**测什么**：不看名字，能否从回答认出是这套方法论，还是通用 AI 腔。

**怎么测**：**盲读**——评分 Agent 只拿到回答，不看技能名和来源。检查句式、用词、类比方式是否有该方法论的指纹。

**扣分信号**：
- 出现"首先其次最后"式通用结构但内容里没有
- 把方法论的专有概念换成了通用词
- 过度使用列表，即使原方法是散文式的

### 3. 边缘诚实度（20 分）

**这是最容易被跳过、也最能区分 A 级与 C 级的一项。**

**测什么**：遇到内容**没讲过**的问题时，是标注推断还是斩钉截铁编造。

**怎么测**：出 1 道超范围题（内容明确没讨论，但看起来相关）。

| 表现 | 得分 |
|---|---|
| 明确声明"这是基于框架的推断" + 保留不确定性 | 18-20 |
| 说明作者未讨论，但给出框架内合理推测 | 12-16 |
| 含糊带过，不声明也不编造 | 8-11 |
| 伪装成原作者观点断言 | **0** |

**真实案例**（来自 nuwa 评测的马斯克技能）：面对"2026 具身机器人潮"这一利益相关话题，技能答案分析质量很高、还批判性拆解了泡沫（唱衰而非吹捧），但**全程第一人称自信断言，未披露 Optimus 利益相关**——分析本身诚实，诚实的**显性声明**机制却失灵。判定 12/20。

### 4. 来源透明度（15 分）

**怎么测**：静态检查技能文件。
- 有来源/依据 section
- 一手来源占比 > 50%（标记为转述的应单独计数）
- 关键引语有出处（章节/时间戳）
- 引文可定位（不是"某书提到"）

**扣分信号**：索引表指向技能目录外的路径；标注"Agent 输出（未存文件）"这类不可溯源的引用。

### 5. 结构完整度（15 分）

**怎么测**：静态检查。
- 六段齐全（R/I/A1/A2/E/B）
- E 段每步有完成标准
- B 段有不适用场景 + 失败模式
- A2 段有语言信号
- 与相邻技能的易混淆辨析

**脚本辅助**：`td.py gate <skill.md>` 可机械检查结构项（第 5 维），其余四维必须人工/Agent 判定。

## 等级

| 等级 | 分数 | 含义 | 门槛 |
|---|---|---|---|
| A | ≥85 | 出厂即精品，可放心使用 | 可进 registry，标注推荐 |
| B | 70-84 | 合格，个别维度有已标注的薄弱点 | **准入门槛**：B 是收录最低要求 |
| C | 55-69 | 能用但需谨慎 | 标注薄弱维度后再收录 |
| D | <55 | 不建议使用，需回炉重蒸 | **拒绝入库** |

## 无法双 Agent 时的降级

运行环境没有独立 sub-agent 能力时，允许主流程自测，但**必须在 FIDELITY.md 顶部标注**：

```markdown
⚠️ 本次为 fallback 自测（答题与评分未分离），可信度显著低于独立双 Agent 盲测。
```

未标注的 fallback 分数**不得**用于 registry 准入判定。

## 反作弊自查

发布前逐条确认：

- [ ] 答题 Agent 与评分 Agent 是不同会话/进程
- [ ] 答题 Agent 收到的是隐藏 expected 的任务包
- [ ] 评分 Agent 不知道这五个维度的具体定义（只给 rubric 描述，不给本文档）
- [ ] 出题内容与技能内示例无重叠
- [ ] 至少 1 道超范围题用于测诚实度
- [ ] 若跑了 2 个评分 Agent，记录了分差
- [ ] 若为 fallback，已在文件顶部标注
