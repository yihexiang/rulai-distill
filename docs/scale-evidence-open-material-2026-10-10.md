- **抓取**：4 套全部来自维基文库公有领域原文，保留原字形与标点，未现代化改写；每套附 `source_id/title/author/url/license/pages` 元信息（`license` 声明公有领域）。
- **规整**：`corpus-anchor` 把维基文库 wikitext 的 `== 标题 ==` 转 `##`、`{{}}`/`[[]]`/`-{}-` 语言变体标记剥离；净字符与原始规模一致（规整不丢正文）。
- **切片**：`side/<src>/index.json` 给出 `chunk_count`。通鉴/孟子正文带 markdown 标题，切片与抓取段接近 1:1（148/147、38/38）；**韓非子、論語正文用传统编号（章/一之一）而非 markdown 标题，切片退化为 3 块**——这是 `corpus-anchor` 按标题切的真实边界，已在下方如实标注。

## 二、诚实边界（别把"能抓"读成"能切细"）

- **切片粒度依赖标题**：`corpus-anchor` 优先按 markdown 标题切，无标题正文会整卷/整章落进一个 chunk。韓非子、論語因此只切出 3 块，单块 3–6 KB。
  这**不影响建卡**（建卡直接读 `corpus/anchored/*.md` 的 `一之一`/【第N段】细粒度标记），但意味着 P0-3 的 token 节省基准对"无标题长正文"偏低——基准样本 ck-* 取自有标题语料，不代表无标题经典的切片收益。
- **論語更细粒度**：5 个抓取块内含传统 `一之一…七之三七` 编号，约 70+ 条可独立引用段落（见卡片 `source_locator`）。
- **校勘注已隔离**：维基文库夹注（如 一之七 混入的牛鵬濤考据、七之六 黄尚明按语）留在 `## 校勘記` 段，建卡时按"作者举例框跳过"口径处理，不进正文引语。
