## 二、三个设计方案

### 方案 A：纯文档编排（**推荐**）

新增 `references/persona-research-swarm.md`，把 nuwa 的 Phase 1 编排移植为 **Agent 工作流指引**：
模式判定表（G1）+ 每路 prompt 模板（G2）+ 并行纪律与串行降级（G3）+ 落盘纪律（G4）+
深度档一手素材衔接（G5）。脚本层**零改动**。

- **为什么不违反「零网络」**：`td.py` 设计原则 2 约束的是**脚本不发起外部请求**；联网由 Agent 侧工具决定。
  现有 `research init` 已是这个分工——脚本产骨架、Agent 填内容。本方案只是把"Agent 该怎么填"写全。
- **优点**：零新命令、零新依赖、不碰 C11 双副本以外的发布面；与 `persona-need-diagnosis.md`
  （同为"nuwa 移植 + 离线改造后补回的可选分支"）完全同模式；改动最小、可回滚最快。
- **缺点**：执行质量取决于 Agent 是否遵循文档，**无机械强制**；收益未经实测。
- **工作量**：1 份参考文档 + `SKILL.md` §人物蒸馏分支引用 + 1 个守卫（文档存在且被引用）。

### 方案 B：文档 + 机械档位参数（可选增量）

在 A 基础上给 `td.py research init` 加 `--tier quick|standard|deep`：
按档位生成对应路数骨架（quick 只建 3 个车道），`LANE_HEADER` 标注档位，
`research merge` 可按档位校验车道数（quick 档不会因缺 3 个车道报错）。

- **优点**：档位从"文档约定"变成**机械事实**；quick 档不再白建 6 个空文件；
  与已有的三档成本门口径对齐。
- **缺点**：改 CLI 表面，须同步 `--help`、README/GUIDE、`t_cli_handlers_intact` 等守卫；
  子命令参数变体增多。
- **工作量**：A + `research.py` / `td.py` 改动 + 守卫与文档同步。

### 方案 C：脚本层联网深研（**否决**）

给脚本加网络采集能力（requests/curl 拉源后入库）。

- **否决理由**：
  1. **直接违反 `td.py` 设计原则 2**「零网络：全包不发起任何外部请求（字幕/调研/评测均离线）」，
     也与 SKILL.md 边界声明冲突；
  2. 引入第三方依赖与**国内可用性风险**（TRACE 的 T4 子项会直接扣分）；
  3. 把"编造风险"从 Agent 侧转移到脚本侧，**反而更难审**——脚本拉来的二手转述无法像 Agent
     答题那样被 `anchor`/`verify-quotes` 逐条锚定；
  4. 动摇项目核心可信度主张（"可验证、可追溯"依赖一手语料在场）。
- **若将来仍要做**：必须先改声明并公开论证，不能靠加功能悄悄扩大口径。

## 三、推荐与优先级

**推荐 A 先行**；B 视 A 落地后的真实使用反馈再决定；C 不做。

| 优先级 | 动作 | 归属 |
|---|---|---|
| **P1** | 落地方案 A：新增 `references/persona-research-swarm.md`（含 G1–G5 五项）+ `SKILL.md` 引用 + 守卫 | rulai-distill |
| **P2** | 方案 B：`research init --tier` 机械档位 | rulai-distill |
| **P2** | 补一次 **no-skill 对照**：同一人物、给 6 路编排 vs 不给，比产出卡片的一手占比/覆盖车道数/复评等级 | rulai-distill |
| — | 方案 C | **否决** |

### 落地 A 时的三条纪律（写进文档即可，不需要新代码）

1. **默认本地语料优先**：先问用户要一手素材，网络只补缺口维度——这与 `persona-need-diagnosis.md:70`
   已定的口径一致，编排文档不得把它写反。
2. **降级必须留痕**：并行挂起转串行、搜索工具不可用转纯本地，都要在对应车道文件里写明"哪路降级了、
   为什么"，否则 `research merge` 的车道覆盖审计会漏报。
3. **披露未验证**：文档须自带"本编排未经真实用户大规模验证、收益为推断"的边界声明——
   与 `persona-need-diagnosis.md:77` 同口径。

若 A 落地：预期影响 **A 维度（适用性）小幅上行**（人物轴能力边界更完整）、**C 维度持平**
