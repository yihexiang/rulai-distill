# 开放素材卡质量分布评估计划（2026-10-11）

> 目标：把「工具能跑」（112/112 绿、零崩溃）升级为「卡片确实好」——对 4 张新开放素材卡
> （tongjian/mengzi/hanfei/xunzi）做**独立答题 + 独立双评分**，给出质量分布（≥4/5 卡 ≥B）。
> 这是评估文档 P1「质量分布」项的落地。用户已授权跑 LLM 子 Agent（2026-10-11）。

## 一、方法（不造假原则）

1. **独立答题**：每张卡 8 道题，分别由「持技能答题 Agent」和「无技能对照 Agent」作答。
   - 持技能：把卡 SKILL.md 全文作为上下文，要求严格按卡内框架/步骤输出。
   - 无技能：只给原始素材（corpus 片段）+ 同样的题，不给药框架。
2. **独立双评分**：每道答案由 **2 个互不知情的评分 Agent** 按统一 rubric 打分（A/B/C/D + 逐维理由）。
   - 评分 Agent 只读「题 + 答案 + rubric」，不读其他评分者结论（防污染）。
3. **机械信号**（复用 eval-kit）：把答案落盘为 `answers.json` / `answers-baseline.json`，
   待 shell 恢复后跑 `td.py eval-kit utility` 算 locator_citation / verbatim_quote /
   boundary_declared / card_term 的 with-vs-without 增益。
4. **诚实边界**：评分是 LLM 判断，非人类金标准；跨模型（GLM/Hy3/DeepSeek）对照留待后续；
   本批同一模型家族即可，结论标注「同族非跨模型」。

## 二、评分 rubric（A/B/C/D）

- **A（优秀）**：框架用对、定位引用准确可核、给出可操作结论、边界/适用条件声明清楚。
- **B（可用）**：框架大体用对，结论可操作，但引用/边界有一处松散。
- **C（勉强）**：框架部分用到，关键步骤缺失或错位，结论含糊。
- **D（失败）**：没用框架、答非所问、或编造素材外内容。

≥B 视为「卡片有效」；分布目标：4/5 卡 ≥B（含既有 lunyu/five-affairs 已示范）。

## 三、各卡 8 道题

### tongjian-decision-trace（通鉴·决策追踪）
1. 给定「某部门刚上线一项新考核」，用名分线判断它动用了谁才能授出的东西。
2. 上述举措，触了哪几类人的利益？列出可观察信号。
3. 反噬通常在多久后、以什么形态出现？给出追踪节奏。
4. 这一步该撤 / 改 / 留？用卡内三步法给结论。
5. 把「领导口头表扬但迟迟不发文」用利益线解读。
6. 一项举措同时动名分+利益，优先追踪哪条线？为什么。
7. 用卡内方法复盘一个你熟悉的真实决策失误。
8. 卡的框架在「自己下的举措」上怎么用（自我审查）？

### mengzi-refutation（孟子·当场纠偏）
1. 同事说「努力没用，出身决定一切」，用取譬设问当场改他的判断。
2. 对方坚持「省钱就是不浪费」，造一个他答得出口的情境让他自相矛盾。
3. 用「以羊易牛」式前提（对方已承认的事实）推导一个他不愿接受的结论。
4. 什么情况下**不该**当场纠偏（卡的边界）？
5. 把纠偏的话写成 3 句以内的对话示范。
6. 对方是权力高于你的一方，取譬设问要改什么？
7. 区分「纠偏」与「说教」，用卡内判据。
8. 用卡的方法处理一个你亲历的被错误判断的场景。

### hanfei-upward-advice（韩非·向上谏言）
1. 你要向老板反对一个他已公开支持的决定，按说难七种先算代价。
2. 老板真正要的是「名高」还是「厚利」？怎么在开口前判断。
3. 哪种说法会让你「身危」？列卡内至少三种。
4. 写一段既把意见说清、又不触发身危的开口示范。
5. 对方阴/显的偏好不同，说法怎么调？
6. 坏消息怎么递，既不瞒也不引爆？
7. 卡的框架在「平级」反对意见上是否适用？边界在哪。
8. 用卡复盘一个你见过的「说真话被罚」案例。

### xunzi-learning-order（荀子·学习次序）
1. 给定「想转行做数据」，按次第排学习顺序并说明起讫。
2. 用积渐解释「为什么每天学一点比突击有效」，给可操作节奏。
3. 专一原则怎么帮你拒绝「同时学三门」的诱惑。
4. 环境（蓬生麻中）如何选？给你当前环境打分并给改法。
5. 内化检验：怎么知道自己真学会了 vs 只会背。
6. 卡说「始乎诵经终乎读礼」，对你选定的方向这意味着什么。
7. 什么算「行衢道者不至」？举一个你半途而废的例子对照。
8. 用卡给一个「学了一年没长进」的人开诊断单。

3. shell 恢复后跑 eval-kit 算机械信号，汇总分布报告。
