# 人类复评包 · 总说明（P1-3）

> 协议：`references/independent-recheck-protocol.md`｜聚合器：`scripts/tdlib/independent_recheck.py`
> 建立日期：2026-10-15｜**当前人类复评例数：0**

## 为什么需要这个目录

`references/independent-recheck-protocol.md` 的诚实边界写明：

> 1 份复评只能降「结构独立」风险，不能消除；**建议每卡 ≥2 份异源复评（跨模型 + 人类各一份）才算稳健。**

截至 2026-10-15，三张人物卡各只有 **1 份跨模型复评**（DeepSeek `deepseek-v4-pro`，8/8 consistent、
重申 A、无编造）。缺口在**人类这一份**。本目录就是为补它而备的**开工包**——材料、口径、模板、
落点全部写好，拿到手就能干活。

## 为什么不用"第二个模型族"顶上

试过且不成立，理由记在这里免得反复：

| 候选第二源 | 为什么不算异源 |
|---|---|
| DeepSeek 同族不同档位（如 `deepseek-v4-flash`） | 同提供商家族。本项目口径：**换档位 ≠ 换家族**，与「跨模型复评仍是 0 例」时期把 `scores-3-crosstier.json` 判为"不同档位会话的复现"是同一条纪律 |
| WorkBuddy 平台模型 | 与卡片作者同族——三张卡的建卡/答题/评分都由本项目主 Agent 完成，用它复评是同族自证 |
| 再跑一次 DeepSeek v4-pro | 同一模型同一版本，最多算重复采样，不增加独立性 |

所以**唯一合法的第二源就是人类评者**（或一个我们尚未接入的第三方厂商模型）。

## 怎么用

1. 挑一张卡，打开对应的 `<card>.md` 包；
2. **先独立读卡 + 底稿 + rubric，自己出 8 题、自己答、自己盲评**——**不要先看** `docs/independent-recheck/<card>/deepseek-v4-pro/review.json`，看完就容易锚定在别人的结论上；
3. 把自己的 `review.json` 写到包内指定的精确路径；
4. 在仓库根跑 `python3 scripts/tdlib/independent_recheck.py`，台账自动更新。

## 诚实边界（复评者必须守）

- **若复评者就是建卡者本人**，须在 `independence_note` 里如实写明（例如"作者本人复评，非独立第二人"）。
  这种情况下该复评**只算「作者自评的人类交叉」**，仍然**不算**协议定义的"第二人复评"——台账会记它，
  但对外宣称时不得把它说成独立人类复评。
- 发现编造必须写 `verdict: "fabrication"` 且 `fabrication_flagged: true`。**这份复评会因此作废**
  （不计入组织独立），并须回写缺陷台账、回卡修复。如实报问题比拿一份好看的 A 有价值。
- 不先看别人的复评结论；看完后再对照，差异写进 `notes`。
