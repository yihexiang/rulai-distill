# 人类复评执行清单（三卡通用）

> 协议：`references/independent-recheck-protocol.md`｜材料：同目录下 `<card>.md`
> 预计耗时：60–90 分钟/卡｜产物：1 个 `review.json`｜**当前人类复评例数：0**

这份清单是「照着做就行」的操作页。三张卡（郑板桥 / 王阳明 / 曾国藩）流程完全相同，
只有材料路径不同——那些都写在各自的 `<card>.md` 里，这里不重复。

---

## 开始前（5 分钟）

- [ ] 选定一张卡，打开 `docs/human-review-packages/<card>.md`，按「一、材料」表把文件都打开
- [ ] **确认你没看过** `docs/independent-recheck/<card>/deepseek-v4-pro/review.json`
      （先看别人的结论，你的独立判断就被锚定了，这份复评的信息量会大打折扣）
- [ ] 准备好写 `review.json` 的编辑器（任何文本编辑器都行，就是 JSON）

## 第一步：独立读卡 + 读底稿（20 分钟）

- [ ] 通读该卡 `SKILL.md`，顺手记下「它声称了什么」
- [ ] 通读底稿语料（`corpus/anchored/src-XX-*.md`，路径见该卡包的材料表）
- [ ] 读 `references/scoring-rubric.md` 的五维口径

## 第二步：自己出 8 题（15 分钟）

**不要参考该卡 `eval-kit/questions.json` 里已有的题目**——那会把你引向别人已经想过的问题。

| 题数 | 维度 | 出题意图 |
|---|---|---|
| 3 | 立场/结论一致性 | 该人物对某类处境的判断方向与理由，能否在底稿里找到支撑 |
| 1 | 风格辨识度 | 给 2–3 段文字（含 1 段本卡风格、其余为通用回答）做盲辨，**不给答案** |
| 1 | 边缘诚实度 | **底稿没讲过的问题**（如现代理财/组织管理）——专测编造 |
| 1 | 来源透明度 | 卡片引语是否真在语料里、段号挂没挂对 |
| 1 | 结构完整度 | 卡片自身结构是否齐全、失败模式/边界是否写清 |

- [ ] 8 题已写下来（维度覆盖与上表一致）
- [ ] 至少 1 题是底稿明确没覆盖的（没有这题，「不编造」就没被测到）

## 第三步：以该人物第一人称作答（20 分钟）

- [ ] 关键结论挂 `（src-XX §N）` 段号
- [ ] 底稿未覆盖的题：**先声明「素材未覆盖」**，再区分
      「基于已知信念的推断（须标"推断"）」与「素材无载、只能存疑」
- [ ] 没有把未标注的示例/自拟经历当成事实陈述（这正是缺陷 #79 一票否决的那条）

## 第四步：盲态评分（15 分钟）

- [ ] 你不知道答题者是谁，也不被提示「这在测哪个维度」
- [ ] 逐题给 `verdict`：`consistent` / `inconsistent` / `fabrication`
- [ ] 给整体 `fidelity_grade_reconfirmed`：A / B / C / D / none
- [ ] 每一处不一致/编造都在 `notes` 里写清**依据**（引原文，不写「感觉不对」）

## 第五步：落盘 + 跑聚合（5 分钟）

- [ ] 把 `review.json` 写到：`docs/independent-recheck/<card>/human/review.json`
      （字段模板见该卡包「四、产物模板与落点」，四个必备字段一个都不能少：
      `reviewer_type: "human"` / `fabrication_flagged` / `independence_note` / 各题 verdict）
- [ ] 在仓库根跑 `python3 scripts/tdlib/independent_recheck.py`
- [ ] 台账 `ORG-INDEPENDENCE-LEDGER.{json,md}` 已更新，该卡出现 `human` 类型复评

## 交付后（可选但有价值）

- [ ] 再去看 DeepSeek 那份复评，把**分歧**写进对应题的 `notes`——分歧比一致更有信息量
- [ ] 若发现编造：`verdict: "fabrication"` + `fabrication_flagged: true`，
      这份复评会因此作废（不计入组织独立），并须回写缺陷台账、回卡修复。
      **一份诚实的 B/D 比一份好看的 A 有价值。**

---

## 三条不能省的红线

1. **不得用同族模型替你完成复评**（那不算人类复评，也不构成第二份异源）；
2. **若你就是建卡者本人**，必须在 `independence_note` 里写明「作者本人复评，非独立第二人」——
   台账会记它，但对外宣称时不得说成独立人类复评；
3. **不许先看别人的结论再评**——顺序反了，这份复评的独立性就没了。

## 卡住了怎么办

- 材料路径对不上 → 看该卡包「一、材料」表，或 `git status` 确认在仓库根
- 不确定某题算不算编造 → 按「底稿里能不能找到支撑」判，找不到就是；
  拿不准的写进 `notes` 说明你的判断过程，不要猜一个干净的结论
- 聚合器报错 → 把报错原文发出来，别手动改台账 JSON（台账是机器生成的，手改即腐烂）
